# Screenshot Guide

Use this guide to collect screenshots for the WRL101 project report.

## Recommended Screenshots

1. Dashboard page
   - Shows the main student overview.
   - Capture the metrics, coursework progress, study task progress, upcoming assignments, and study focus panel.

2. Sidebar navigation
   - Shows how users move between pages.
   - Capture the sidebar with all navigation options visible: Dashboard, Assignment Tracker, To-Do List, Timetable, Notes, Academic Support, and Testing.

3. Assignment Tracker page
   - Shows how engineering coursework is organised.
   - Capture the tracker summary, coursework table, assignment progress chart, and detailed assignment rows.

4. To-Do List page
   - Shows weekly student task management.
   - Capture the task metrics, checklist, and planning notes.

5. Timetable page
   - Shows the weekly academic schedule.
   - Capture the weekly overview table and several timetable cards.

6. Notes page
   - Shows how students can store study notes and report planning points.
   - Capture saved engineering notes, quick capture box, and report checklist.

7. Academic Support page
   - Shows student support services.
   - Capture the support directory, available services metric, and contact details.

8. Testing page
   - Shows evidence of prototype testing.
   - Capture the testing metrics, feature test table, and testing summary.

## Screenshot Tips

- Run the app with `streamlit run app.py`.
- Use a full browser window so the tables and columns are easy to read.
- Make sure the sidebar is open when taking at least one screenshot.
- Use clear filenames such as `dashboard.png`, `assignment_tracker.png`, `timetable.png`, `notes.png`, and `testing_page.png`.
- In the report, add a short caption under each screenshot explaining what feature it demonstrates.
