# Student Productivity and Academic Support Application

This is a simple Python Streamlit prototype for the WRL101 university project.

The application is designed to help students organise academic work in one place. It includes:

- Dashboard page
- Assignment tracker page
- To-do list page
- Timetable page
- Notes page
- Academic support page
- Sample data for screenshots and report discussion

The prototype does not use databases, login systems, APIs, or complex backend features. All sample data is stored directly inside `app.py`.

## How to Run

1. Install Python on your computer if it is not already installed.
2. Open a terminal in this project folder.
3. Install the required packages:

```bash
pip install -r requirements.txt
```

4. Run the Streamlit app:

```bash
streamlit run app.py
```

5. Streamlit will open the app in your browser. If it does not open automatically, copy the local URL shown in the terminal.

## Project Purpose

This app is a working prototype for a university report. It demonstrates how a student productivity and academic support application could look and function at a basic level.

## Files

- `app.py` contains the Streamlit application code.
- `requirements.txt` lists the Python packages needed to run the app.
- `README.md` explains the project and setup steps.
